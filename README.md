# BookHaven – Library Management System

## Project Overview
BookHaven is a web-based Library Management System developed to help librarians manage books, registered members, and borrowing and returning transactions.

## Technologies Used

**Frontend**
- React.js
- JavaScript
- CSS
- React Hooks

**Backend**
- Node.js
- Express.js
- MySQL
- REST API
- bcryptjs

## Main Features
- Dashboard displaying library information and statistics.
- Add, view, update, and delete books.
- Manage registered library members.
- Record book borrowing and returning transactions.
- Update book stock quantities.
- Search and manage library records.
- Librarian login and registration.

## Project Structure

- `Frontend/` – React application.
- `Backend/` – Express server, database connection, and API routes.

## How to Run the Project

**1. Backend**

Open the Backend folder and run:

```bash
npm install
npm start
```

**2. Frontend**

Open the Frontend folder and run:

```bash
npm install
npm run dev
```

Configure your MySQL database credentials in the Backend `.env` file before starting the server.

## Database
The project uses MySQL to store books, users, login accounts, and transaction records.
